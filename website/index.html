The see command

Straight from
your shell.

Install the see command from the command palette, then open any folder or file without leaving the terminal.

If See is already running, the path is handed to it — an open folder comes forward, a file opens in the window that holds it.

# open the current folder
~/code/see $ see .
# open a file in its parent folder
~/code/see $ see internal/git/history.go
# or any project, anywhere
~ $ see ~/code/mygo
